云同步（Firebase）

家长与孩子使用同一家庭码即可共用一份数据：规则、历史记录、今日未提交的草稿会实时同步（以最后写入为准）。托管在 GitHub Pages 时也是用 https://… 打开（不要用 file://）。

家长：首次如何配置 Firebase（免费）
  1. 打开 Firebase 控制台，创建项目（可不启用 Analytics）。
  2. 项目里添加「网页」应用，复制网页配置对象里的 apiKey、authDomain、projectId 等字段。
  3. 左侧打开「Firestore Database」→ 创建数据库 → 选就近区域；规则可先改为测试模式，或粘贴规则允许按文档 ID 读写（见下）。
  4. 托管在 GitHub：仓库 Settings → Pages 启用站点，记下访问地址（例如 https://你的用户名.github.io/仓库名/）。到 Firebase 项目设置 → 你的应用 → 已授权的网域，添加与地址栏一致的主机名（一般是 你的用户名.github.io，不要带路径）。本地调试时保留 localhost。
  5. 在本页源码中搜索 FIREBASE_CONFIG，把占位内容换成你的配置并提交到仓库（公开仓库里也会看到配置，这是 Firebase 网页应用的常态，请靠 Firestore 规则 + 保密的家庭码 保护数据）。
  6. 全家人在上方「家庭码」里填完全相同的一串字符（建议较长、勿公开）。

Firestore 规则示例（控制台 → 规则）— 知道家庭码的人可读写，请把家庭码当作密码：
match /family_score/{id} { allow read, write: if id.size() >= 4 && id.size() <= 64; }
